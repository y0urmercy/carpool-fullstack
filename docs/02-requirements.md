# Требования

## User Stories

| ID    | Роль     | Хочу                                | Чтобы                                 | Приоритет |
| ----- | -------- | ----------------------------------- | ------------------------------------- | --------- |
| US-01 | Водитель | создать поездку с маршрутом и ценой | найти попутчиков                      | Must      |
| US-02 | Пассажир | забронировать место                 | добраться дешевле такси               | Must      |
| US-03 | Водитель | подтверждать/отклонять заявки       | контролировать состав пассажиров      | Must      |
| US-04 | Пассажир | отменить бронь без штрафа за 2 часа | не терять деньги при изменении планов | Should    |
| US-05 | Пассажир | оставить оценку после поездки       | помочь другим выбрать водителя        | Could     |

## Функциональные требования (FR)

| ID    | Формулировка                                                                                  | Приоритет |
| ----- | --------------------------------------------------------------------------------------------- | --------- |
| FR-01 | Водитель может создать поездку с указанием маршрута, времени, количества мест и цены за место | Must      |
| FR-02 | Пассажир может отправить заявку на бронирование конкретного места                             | Must      |
| FR-03 | Водитель может подтвердить или отклонить заявку пассажира                                     | Must      |
| FR-04 | Система рассчитывает итоговую стоимость и удерживает комиссию сервиса (5%) при подтверждении  | Should    |
| FR-05 | Пользователь может отменить поездку/бронь не позднее чем за 2 часа до отправления без штрафа  | Should    |
| FR-06 | После завершения поездки пассажир и водитель могут оставить друг другу оценку (1–5)           | Could     |

## Нефункциональные требования (NFR)

| ID     | Категория          | Формулировка                                                                       |
| ------ | ------------------ | ---------------------------------------------------------------------------------- |
| NFR-01 | Производительность | Время отклика API при создании поездки — не более 500 мс при нагрузке 100 RPS      |
| NFR-02 | Безопасность       | Все персональные данные передаются только по HTTPS и хранятся в зашифрованном виде |
| NFR-03 | Доступность        | Сервис доступен 99.5% времени в месяц (допустимый простой ~3.6 часа)               |
| NFR-04 | Масштабируемость   | Архитектура позволяет горизонтальное масштабирование без изменения кода            |
| NFR-05 | Наблюдаемость      | Все запросы логируются с request_id для трассировки                                |
