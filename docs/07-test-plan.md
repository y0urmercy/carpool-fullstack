# Программа и методика испытаний (ПМИ)

## 1. Цель

Проверить корректность работы API CarPool согласно требованиям FR-01 — FR-05.

## 2. Объект тестирования

REST API, реализованный на FastAPI.

## 3. Тест-кейсы

### TC-01: Создание поездки с корректными данными

- **Шаги:** POST /trips `{"driver_id":1, "origin":"A", "destination":"B", "departure_time":"2026-01-01T10:00:00", "seats":2, "price":500}`
- **Ожидаемый результат:** 201 Created, тело содержит `seats_total=2`

### TC-02: Создание поездки с 0 мест

- **Шаги:** POST /trips `{"seats":0}`
- **Ожидаемый результат:** 422 Unprocessable Entity

### TC-03: Бронирование при наличии мест

- **Шаги:** Создать поездку на 2 места, затем POST /trips/{id}/bookings
- **Ожидаемый результат:** 201 Created, статус PENDING

### TC-04: Бронирование при отсутствии мест

- **Шаги:** Создать поездку на 1 место, забронировать, затем ещё раз
- **Ожидаемый результат:** 409 Conflict

### TC-05: Получение несуществующей поездки

- **Шаги:** GET /trips/9999
- **Ожидаемый результат:** 404 Not Found

### TC-06: Отмена брони за 3 часа до отправления

- **Шаги:** DELETE /bookings/{id} при departure_time через 3 часа
- **Ожидаемый результат:** 200 OK, штраф 0

## 4. Критерии приёмки

Все тест-кейсы должны пройти успешно. Покрытие ключевых эндпоинтов — 100%.
