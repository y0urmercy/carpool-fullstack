
# Карта стейкхолдеров

| Стейкхолдер      | Тип                  | Власть  | Интерес | Ключевая цель                                                         |
| ---------------- | -------------------- | ------- | ------- | --------------------------------------------------------------------- |
| Водитель         | Внешний пользователь | Высокая | Высокий | Компенсировать расходы на топливо, найти попутчиков без лишних усилий |
| Пассажир         | Внешний пользователь | Низкая  | Высокий | Дешево и предсказуемо добраться до пункта назначения                  |
| Служба поддержки | Внутренний           | Низкая  | Средний | Минимизировать количество конфликтов и возвратов                      |
| Финансовый отдел | Внутренний           | Высокая | Низкий  | Обеспечить прозрачность транзакций                                    |
| Разработчик      | Внутренний           | Средняя | Высокий | Получить четкие, тестируемые требования без «белых пятен»             |

## Конфликт интересов

**Водитель** хочет максимизировать цену за место.
**Пассажир** хочет минимизировать цену.
**Разрешение:** система рассчитывает рекомендованную цену на основе расстояния и средней стоимости топлива; водитель может отклониться не более чем на 20%.
