# CarPool — Сервис совместных поездок

**Пет-проект системного аналитика + разработчика.**  
Спроектирован и реализован MVP веб-сервиса для поиска попутчиков: водитель публикует маршрут, пассажир бронирует место, система рассчитывает долю расходов.

## 🎯 Что демонстрирует этот проект

| Роль                   | Артефакты                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| **Системный аналитик** | Карта стейкхолдеров, FR/NFR, User Stories, BPMN As-Is/To-Be, ERD (Crow's Foot), OpenAPI 3.0, ПМИ |
| **Разработчик**        | FastAPI, SQLAlchemy, SQLite, Pydantic, pytest, Docker-ready                                      |

## 🚀 Быстрый старт

```bash
git clone https://github.com/your-username/carpool-fullstack.git
cd carpool-fullstack
pip install -r requirements.txt
uvicorn app.main:app --reload
```
